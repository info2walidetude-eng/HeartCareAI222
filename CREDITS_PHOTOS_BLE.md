# Images locales BLE

Cette version embarque directement dans l'application trois images locales pour l'affichage hors ligne :

- **ble_smartwatch.png** : montre intelligente
- **ble_optical_sensor.png** : capteur optique
- **ble_chest_strap.png** : ceinture cardiaque

Les images sont stockées dans `app/src/main/res/drawable-nodpi/`.
