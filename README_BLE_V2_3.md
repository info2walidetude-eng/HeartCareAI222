# HeartCare AI – BLE V2.3

## Modifications de l'écran BLE

L'écran **Capteurs BLE** a été simplifié pour afficher 3 grands types d'appareils compatibles :

1. **Montre intelligente**
2. **Capteur optique**
3. **Ceinture cardiaque**

Pour chaque appareil, l'interface affiche :
- une **photo** de l'appareil,
- son **nom**,
- une **description**,
- son état **Connecté / Non connecté**,
- un bouton **Connecter** si l'appareil est réellement détecté.

## Important

Le statut **Connecté** n'apparaît qu'après une vraie connexion Bluetooth BLE.
Une photo ou un nom dans la liste ne signifie pas qu'un appareil est déjà relié.
